# 알라딘 베스트셀러 대시보드

아주대학교 비즈니스애널리틱스 실습 과제입니다. 수업 공개 예제의 50개 데이터를 사용하고 화면 배치, 색상, 기준일 표시와 가격 구간을 조정했습니다.

- 전체 도서 수, 평균 가격, 최고 가격, 출판사 수 요약 카드
- 가격대별 도서 수 막대차트와 출판사별 도서 수 상위 8개 도넛차트
- 제목·저자·출판사 검색, 출간연도 필터, 모든 열의 양방향 정렬
- 모바일 화면 대응 및 빈 검색 결과 안내

배포 주소: https://hyunik2-code.github.io/bestseller-dashboard/

`index.html` 하나에 데이터와 스타일, 동작 코드가 들어 있습니다. Chart.js 4.4.8은 공개 CDN에서 불러옵니다. API 키나 로그인 정보는 포함하지 않습니다.

데이터 기준일은 영상의 과제 화면에 명시된 2026년 9월 8일입니다. 실시간 베스트셀러 순위가 아닙니다. 세트 상품도 한 개 항목으로 집계하며 요약·차트는 전체 데이터, 검색·필터는 표에 적용됩니다.

수업 예제 및 데이터 출처: https://github.com/newspap2r/bestseller-dashboard

GitHub Pages 설정: Deploy from a branch → main → / (root).
